# Security Policy

## Supported Versions

Only the latest commit on `master` of this fork is supported. There are no published releases; build from source (see [Installation](docs/02-installation.md)).

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not create a public issue**.

Report it privately through GitHub's private vulnerability reporting for this repository: open the [Security tab](https://github.com/bdpdx/slack-mcp-server/security) and choose **Report a vulnerability**. Include as much detail as possible:

- Steps to reproduce the vulnerability
- Affected commit or version
- Potential impact
- Any suggested remediation (if available)

This fork is maintained independently of the upstream project ([korotovsky/slack-mcp-server](https://github.com/korotovsky/slack-mcp-server)); report upstream-only issues there.

## What to Expect

- We will confirm receipt of your report.
- We will investigate the issue and may reach out for further details.
- Once the issue is confirmed, we will fix it on `master` and coordinate disclosure with you.

## Responsible Disclosure

Please do not publicly disclose the vulnerability until a fix is available, and give us adequate time to address it.
